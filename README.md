# Realm of Atlas RPG

Browser-based RPG with turn-based combat, skills, exploration, and a set of data-driven
gameplay systems: quests + a main story arc, elemental Trial gauntlets, crafting (the Forge),
hireable companions, faction reputation, and special encounters (elite enemies + roadside
events).

- **Systems & how to extend them:** `SYSTEMS.md`
- **Combat design / known pain points:** `COMBAT_ARCHITECTURE.md`, `COMBAT_BUGS.md`
- **Adding areas/content:** `CONTENT_GUIDE.md`
- **Repo conventions & operating rules:** `CLAUDE.md`

Split out from the hub repo into its own standalone project repository.
